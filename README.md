# KCT College Website

A modern, responsive, and user-friendly college website developed for **Kumaraguru College of Technology (KCT), Coimbatore** using HTML5, CSS3, JavaScript, Bootstrap, Bootstrap Icons, and Google Fonts.

---

## 📌 Project Overview

The **KCT College Website** is a multi-page front-end web development project designed to present important information about **Kumaraguru College of Technology (KCT), Coimbatore** in a clean, professional, and responsive format.

The website provides visitors with information about the institution, academic programmes, achievements, campus highlights, recruiters, and contact details.

This project was developed to demonstrate practical knowledge of front-end web development technologies including **HTML, CSS, JavaScript, and Bootstrap**.

---

## 🎯 Objectives

The main objectives of this project are:

- To design a professional and modern college website.
- To create a responsive and user-friendly interface.
- To provide information about Kumaraguru College of Technology.
- To display academic programmes and courses.
- To create multiple interconnected web pages.
- To practice HTML5 for website structure.
- To use CSS3 for styling and responsive design.
- To implement JavaScript for interactive elements.
- To use Bootstrap for responsive layouts and UI components.
- To use Bootstrap Icons for attractive visual elements.
- To implement hover effects and interactive components.
- To understand responsive web design principles.
- To create a functional contact form.
- To learn Git and GitHub version control.
- To improve front-end web development skills through a real-world project.

## 🌐 Website Pages

### 🏠 Home Page
The **Home Page** serves as the main landing page of the website. It provides visitors with an overview of Kumaraguru College of Technology and includes:
- Hero Section
- College Introduction
- College Statistics
- Key Features
- Important Highlights
- Recruiter Information
- Navigation Links
- Call-to-Action Sections
- Footer Section

### 🏫 About Page
The **About Page** provides detailed information about Kumaraguru College of Technology. It includes:
- Who We Are
- Vision
- Mission
- Campus Highlights
- Achievements
- Reasons to Study at KCT
- Institutional Information
- Campus-Related Content

### 🎓 Courses Page
The **Courses Page** presents the academic programmes available at the institution. The page includes information such as:
- Undergraduate Programmes
- Postgraduate Programmes
- Programme Names
- Course Duration
- Programme Descriptions
- Academic Information

### 📞 Contact Page
The **Contact Page** allows visitors to find the institution's contact information and submit enquiries. It includes:
- College Address
- Phone Number
- Email Information
- Contact Form
- Location Map
- Contact Submission Interaction
- Social and Navigation Information
